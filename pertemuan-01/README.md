1. Konsep Dasar Pemrograman Web
   proses pembuatan aplikasi melalui internet menggunakan peramba(browser), yang didasarkan pada arsitektur Client-Server
2. Arsitektur Klien-Peladen
   struksi aplikasi terdistribusi yang membagi tufas anatar pihak pemohon layanan(klien) dan pihak penyedia sumber day atau
   layanan(peladen)
3. HTTP Request dan Response
   siklus komunikasi antara kalien
4. HTML, CSS, JavaScript, PHP, MySQL
   HTML: HTML merupakan bahasa markup standar untuk halaman web, yang digunakan untuk membuat dan menyusun bagian, paragraf, dan link          menggunakan elemen HTML, yaitu komponen dasar halaman web seperti tag dan atribut.
   css: 
   untuk membedakan desain visual website dari tampilan konten. HTML mengatur sususnan konten website, sedangkan CSS mengatur desain
   visual    dan estetikanya.
   java script:
   JavaScript atau kita singkat menjadi JS merupakan bahasa pemrograman jenis interpreter, sehingga kamu tidak memerlukan compiler untuk     menjalankannya. JavaScript memiliki fitur-fitur seperti berorientasi objek, client-side, high-level programming, dan loosely typed.
   PHP:
   adalah bahasa skrip sisi server open-source yang umum digunakan di bidang pengembangan web.
   MySQL:
   MySQL adalah sistem manajemen basis data relasional (DBMS) yang bersifat open source.
5. Hubungan Antarteknologi
